### Installation:

1. Call cmd : WIN + R

2. Enter the file path (change to real path) : 
cd /d D:\my_web_project

3. A the virtual environment : 
venv\Scripts\activate

4. Download requirement : 
pip install -r requirements.txt

5. Run the website : 
python run.py
